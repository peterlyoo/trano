# Trano development

- Start with `docs/PROGRESS.md`, `docs/RTM.md`, `docs/RECOVERY.md`, and `docs/NAVIGATION.md`. The original requirements are `U01` through `U21` in `docs/PRD.md`. Preserve them when continuing work; milestone documents are planning baselines, not current completion evidence.
- This is a native macOS app with a Linux SSH helper. Keep the public product independent of private agent harnesses and private provider integrations.
- Minimize user steps: choose useful defaults, make optional names automatic, and use native selection controls for installed options such as fonts. Transient navigation must dismiss on outside click and Escape without requiring a close button.
- Use visible labels for profile creation/deletion. Transient keyboard hints belong in a stable noninteractive slot, separate from close/destructive targets, and must cancel with modifier release, editing/modal state and owner/app focus loss.
- Give every terminal pane a stable SwiftUI identity. Test native tab creation and repeated switches with real attach clients and backend PIDs; backend-only action tests cannot detect a renderer reused for another pane.
- Pane tear-off windows must load existing state without startup recovery, which can restart unrelated retained jobs. Retain native drag sources until completion even when SwiftUI unmounts their headers, and cover both unrelated dead jobs with automatic restore enabled and weak source lifetime in tests.
- Bound terminal titles by UTF-8 bytes before display-width or grapheme truncation; preserve Unicode joiners. Keep formatting independent of DNS: `ProcessInfo.hostName` can block, and tmux already provides its own host for default-title filtering. Coalesced refreshes must retain events arriving after an in-flight read. Use full validated UUID targets for tmux `set-option`; the `=UUID` selector accepted by `attach-session` is not accepted there.
- Live supervisors can retain an older Codable schema after app replacement, so keep new durable queue/read-receipt data in the continuity sidecar and test an old-schema primary-state rewrite without restarting jobs.
- Treat quota/reset metadata as optional: cache failures must not fail terminal actions. Keep banked-reset counts separate from scheduled refresh times, preserve their original observation time, and run provider queries outside the UI queue and shared transaction.
- New agent-facing requests must carry immutable pane/generation identity and verify socket peer ancestry; unread decisions gate Stop and queued sends under the shared transaction, while filesystem workspace strings remain verbatim.
- On macOS, verify another process's foreground terminal with kernel `proc_bsdinfo.e_tpgid` and tty device identity; `tcgetpgrp` from the background helper can return `ENOTTY`, which real PTY delivery tests must cover.
- Native buttons must retain a valid action owner across SwiftUI redraws; use the native button's own target/action and exercise real clicks after redraw rather than relying on a released representable coordinator.
- Recheck marked text before asynchronous UI navigation completes; passive snapshots must preserve the composing tab/pane too. Native draft editors must skip model writes during composition and retain question identity so an old preedit cannot enter another question's draft.
- Native context-menu actions must own their targets, freeze workspace/tab/pane IDs and revalidate at mutation commit, including after rename dialogs. Queued close actions must recheck input before committing, and focus restoration must respect native sheets/modals.
- Keep queued-input pane binding independent of tab selection. Freeze passive selection for composition or actual native modals; merely displaying the queue must not prevent explicit tab switching.
- Picker management targets must use workspace IDs and preserve query/editor and selected result identity through reorder/removal. Fixed footer actions must retain keyboard selection and filtered creation behavior; verify their native bounds outside the scrolling rows. If queued actions depend on live input state, validate at the queued work's start before runtime locks; do not validate on main and enqueue a second mutation behind other work.
- ARC-owned windows must use `isReleasedWhenClosed = false`; exercise native close animations and autorelease drainage without terminating backend jobs.
- Align native window controls using the shared header height and current parent coordinate conversion after AppKit update/resize. Preserve the standard button objects/actions; check rendered 1×/2× sizes, clipping and edge hit targets as well as frame values.
- Run animated-window deallocation fixtures in a bounded fresh XCTest process to control shared AppKit state. Keep the original repeated-close and deallocation assertions, and prove the child ran the intended test.
- Transfers must reconcile every window mirroring the source workspace and consult floating ownership across the runtime, including when the destination closes before its queued transfer commits. Route menu and keyboard actions through the same window owner.
- Tab dragging transfers tabs between windows or detaches into a new window; window-background dragging moves the parent window. A drag preview or direct `receive` call does not qualify the gesture. Verify native source hit targets, private payload/move negotiation, accepted/canceled completion, actual window creation and unchanged jobs. Workspace destinations use explicit IDs; hover must retain immutable source identity. Keep drag chooser bounds inside the owning window and use cached roots/ownership for its polling.
- Keep ordinary tab clicks on the existing composition-preserving selection pipeline. Drag eligibility must not suppress clicks while marked text or queued input is present; validate drag and click ownership separately.
- A closed workspace must stay closed through passive selection, stale navigation requests and queued context restoration. Startup may reuse open tabs or detached live jobs, but must not reattach retained closed-workspace or closed-tab jobs without an explicit reopen.
- Test final-tab and final-pane close through keyboard, tab and menu paths. Advance from the closed workspace's position, including passive mirrors; retain generic transfer detach semantics. Queued closes must capture exact IDs and validate at queue start, and keyboard focus must move after the result applies without adopting another window's selection.
- Real `ApplicationDelegate` shortcut dispatch requires `observeSettings(model, window:)` to populate `keyMaps`. Preseed inert terminal renderers and `AppStore(startServices:false)` for no-job native fixtures. Assert handle accepted, stored layout, successor renderer window identity, and no window close.
- Native search editors must route navigation selectors explicitly while preserving marked text. Offscreen `CGWindowList` results do not establish visible window order; verify owned-window visibility and input state, and keep physical screen qualification separate.
- Run `swift test` with full Xcode. Build with `scripts/build-app.sh`; the result is `build/Trano.app`. Do not run concurrent Swift builds in the same `.build` directory or overwrite an executing binary in place.
- Finish each completed Trano change with a rebuild and refresh the signed local installation. Verify the installed build identity and running executable paths, while preserving live shell PIDs and layout.
- Foreground program icons must derive from verified process-group identity and bounded executable arguments, separate from coding-agent bindings and terminal output. Keep Swift/Go parser vectors aligned, including empty or hyphen-prefixed option values. Pin bundled artwork provenance and license notices, include their bytes in build identity, and verify the installed resource bundle.
- Use isolated temporary `TRANO_DATA_DIR`, `HOME`, `ZDOTDIR`, and provider profile roots for experiments. Never point destructive tests at a user's runtime or the default tmux server. Generated state, credentials, caches, and logs stay ignored under `.local`, `.build`, or `build`.
- Capture test results and remaining limits in `docs/PROGRESS.md`. Real PTY/renderer tests do not establish real OS IME behavior; fake provider tests do not establish authenticated Claude/Codex compatibility or quota handoff.
- Recovery identity must include a fresh launch generation and the actual provider process ancestry. A child SDK probe can inherit pane IDs and fire its hook before the parent. Test that order explicitly. Record the provider PID before it starts running; never infer identity from UUID timestamps, inherited pane IDs alone, or `--last`.
- Keep `Stop` (turn completion) distinct from process exit. Recovery preserves live processes, layout IDs, account roots, and working directories; it must not replay original prompts or commands. Missing mappings produce diagnostics.
- Test the bundled CLI and native app with `experiments/check-recovery.py` and `experiments/check-native.py` after recovery changes. `TRANO_TEST_CLI` selects the CLI for the recovery/account/remote experiments. Keep an isolated SSH fixture for `experiments/check-remote-ssh.py`.
- Preserve exact UTF-8 arguments and shell quoting for Korean NFC/NFD, spaces, quotes, and trailing semicolons. tmux parses command separators separately from the shell. Do not set `LC_ALL=C` to localize diagnostics.
- Keep runtime and configuration mutation under the shared transaction and ownership checks. Publish no credentials, transcript content, private hostnames, local personal paths, or unreviewed generated data.
- SwiftPM's background XCTest helper cannot acquire a key window. Keep hover owner-key state deterministic in native unit tests, exercise real panels and focus state, and record physical pointer/activation qualification separately rather than weakening production activation guards.
- Account-transfer rollback must validate every backup and prove that installed files and database rows still match the receipt before restoring them. Refuse rollback when newer target work exists; never treat a missing receipt as proof of success.
- SSH recovery must run outside the shared local state transaction. Revalidate pane identity before committing results, and test local state mutation while SSH is deliberately blocked.
- Native benchmarks must verify both the selected tab layout and the reported terminal view count. Preserve raw samples and partial reports across failures, and label backend-only measurements separately.
- A background SwiftUI hosting view may expose only an empty accessibility group. Check its actual accessibility tree before relying on button-driving tests; use real-runtime draft commit/discard tests when that surface is unavailable, and distinguish new-model contract coverage from reproduction of an existing UI bug.
- Overlay containment tests must assert the owning window and workspace bounds as well as unchanged terminal viewport dimensions; a native popover can preserve viewport size while extending outside the app.
- Anchor workspace menus to the measured selector bounds. For terminal-gap reports, compare header, pane-header and renderer origins as well as sizes, then inspect a marked first-row render; an occupied pane title row is not evidence of an unused inset.
- Bound native Settings controls by their measured intrinsic size; use multiple rows for palettes and assert actual horizontal control bounds. A successful bitmap write or nonempty PNG does not prove visual correctness; retain malformed capture evidence and use native control/action checks without claiming physical or visual qualification.
- Validate unnamed-workspace creation at each actual action/API entrypoint, not only the random-name helper. Geometry continuity does not prove opacity; sample boundary alpha at1×/2× before claiming transparent gaps fixed.
- Keep completed fixes independently buildable and install them before waiting for unrelated staged features. Under a user E2E pause, run pure and native-component unit tests only; do not launch real terminal jobs or standalone test apps.
- Review removed hunks in every shared-file stage patch. Keep the immutable implementation base; recapturing a newer base and diffing an old whole-file candidate can silently delete another feature. Merge lifecycle fields and API routes additively and run cross-domain units together.
- Parallel Swift workers must use the isolated-validation wrapper when provided. It must inject absolute package/scratch paths, reject the product root and scratch symlinks, and bound compiler jobs; workdir alone is not an isolation boundary.
- Pending keyboard sequences must freeze both native responder and logical pane identity. Revalidate around hint callbacks and suppress command/control fallback when API-driven focus and responder ownership disagree.
- Hidden, detached, replaced or miniaturized terminal renderers must revoke asynchronous interaction leases; a retained Supervisor panel must invalidate its renderer before hiding it.
- Keep notification sender icon/display metadata in the helper bundle as well as the GUI. Verify both installed resources and Launch Services registration without treating packaging checks as actual OS notification qualification.
- Native history/resume overlays must resolve a floating pane to its ordinary presentation owner before capturing input and loading state. Capture the destination workspace at open; native activation must not publish global navigation that redirects unrelated windows. Successful navigation clears floating return-focus, while cancellation retains it.
- Toolbar icon customization must use context-only hit regions outside disabled primary actions. Keep its direct menu limited to working visibility choices, retain a header recovery path when all icons are hidden, and merge visibility by item ID so concurrent changes to other items/settings survive.
- Explicit appearance opacity must tint the whole window background, including chrome, footer, pane headers, padding and seams, without reducing glyph/control alpha. Paint only exposed padding/anchoring gaps behind a renderer; composite image and base once with the effective profile/glass opacity.
- Verify synthetic image source RGBA and rendered RGB as well as alpha before interpreting captures. NSBitmapImageRep color conversion warnings can leave an intended white fixture transparent; inspect the input bytes before blaming a rendering layer or changing the product architecture.
- Keep default logo colors shared across tab icons and summary/detail renderers. Tab decoration must not force provider glyphs white or add generic white tiles; only explicit icon color and shell theme preferences may override the natural logo palette.
- Asynchronous terminal input replay must revalidate the native key window and first responder for every item, and require an authoritative backend-PID match before treating history exit as success. Input-error banners must also revalidate registered native view and relay lifetime when publishing; retire relays with removed views while retaining backend draft uncertainty. Context actions on an inactive pane must establish its logical and native input ownership before queuing a reset or paste; test window/editor transfers with a delayed fake backend without weakening production focus guards.
- Verify vendor method overridability before planning a native input override: Swift `public` does not imply `open` across modules. Prefer the existing owned-window event route with native hit testing when an override is unavailable; do not widen vendor APIs merely to bypass a failed assumption.
- Classify user input at the actual transport boundary, including delayed clipboard payloads; protocol replies must not invalidate user-draft readiness. Keep per-input metadata below a dedicated child directory and refresh cached readiness without session scans or renderer synchronization on its events.
- Revalidate the captured input destination after every asynchronous history return and modal confirmation. A consumed one-shot attempt still needs an independent final identity check; preserve cancelled voice drafts for explicit review without rerouting or automatic submission.
- Inspect the installed provider's current configuration contract before declaring a generated file unused. Bind organization verification to owned-root authentication mutations, and route final pre-spawn failures through the same generation cleanup and transfer rollback as spawn failures.
- Mirror presentation-side Supervisor authority restrictions at the final continuation commit. A stale capability must not bypass a newly pending decision or blocked Supervisor state.

- Native background helper health must use a bounded cache-only identity probe, a helper-lifetime singleton lease outside the uninitialized runtime root, and serialized API restart/shutdown. Retained failure UI needs an explicit helper exit path when its API is unavailable; invalidate old remote coordinators before replacing listeners. Status-item registration is headless evidence, not physical menu-bar visibility.

- Shared in-window terminals own native descendant editors such as FindBar, not only the terminal view object. Preserve native editing and IME while routing close/zoom to the shared surface; test the actual native editor subtree. Cancel deferred focus after new user input or owner changes, clear obsolete pending owners, and use local home when opening a local shared shell from a remote pane.
- Automatic worktree cleanup requires exact creation provenance and trusted root task completion; keep branch refs and refuse dirty, ignored, active or uncertain targets. Keep Git/process preflight outside runtime transactions, then serialize the final context check and bounded nonforce removal with terminal input admission. Successful provider exit must validate the retained managed input binding without rebinding or synthesizing a clean ledger.
- Native process-use censuses may exclude exited zombies only with exact kernel PID/UID/birth witnesses revalidated after the final membership sample; unknown, live and reused process identities remain blockers.
- Reviewer forks must preserve exact conversation and account identity, use an owned worktree and scoped native commit bridge, and keep human merge authority separate from all model output. Revalidate source files, effective Git policy, process births and owned-resource use at the final mutation boundary; preserve ambiguous artifacts.
- Native offscreen pixel fixtures must pin the view rendering scale to the target drawable scale. A fixed 1× drawable with a detached view inheriting a 2× main display clips valid glyphs and produces misleading empty-pixel failures.
- Window-local outside dismissal must cover native chrome and sheet-owner clicks, invoke the actual Close/Cancel path, and consume the dismissal click. Intersect native visibleRect with bounds, retain field-editor IME/save guards, and defer observable publication during SwiftUI representable teardown while revoking async work immediately.
- Click-away tool windows must not depend on document-modal owner input admission. Keep an exact owned nonmodal native child, bounded to its owner, to preserve key/editor ownership above native floating terminals; test the actual presentation hierarchy and event route. Synthetic sendEvent success alone does not qualify physical pointer admission; Escape must preserve IME and shortcut-recording ownership.
- New default keyboard bindings must yield to already explicit single-key owners and multi-stroke prefixes; keep explicit overrides/disable authoritative and test the native action route plus autorepeat through the shared action catalog.
- Shortcut corrections must test both the requested binding and the rejected alias through native action dispatch and actual picker content; different actions can render the same search shell and make a registry-only check misleading.

- Tool panels must consume the shared interface theme and metrics; explicitly reinject the theme across separate native hosting roots. Apply native color/font styling before existing text/IME equality guards, without replacing editor text, selection, undo or draft owners.
- Native background drawing must fill only `bounds.intersection(dirtyRect)`: an unclipped AppKit dirty/visible rectangle can include sibling content and erase a SwiftUI header. Verify actual header pixels and native button frames as well as marker geometry; native button alignment insets can enlarge a requested 24pt control.
- Agent-exit keyboard handoff must capture process witnesses before the first interrupt and replay original native events against the same shell and stable current modes. Keep replay-started IME composition owned, recheck complete launch history at writer admission, and carry an immutable coalescing key so batching cannot discard a guarded writer.
- Retained IME preedit must follow output-driven cursor movement between input-method events through the shared main-actor frame-effects path, including background Metal. Test delayed commit echo without another marked-text event and preserve the hidden native Metal caret. Composition underlines replace only the rendered ordinary cursor; preserve terminal cursor modes, user styles and raw IME attributes, and verify actual underline/cursor pixels across begin, commit and cancel.
- Native no-job fixtures still validate Unix socket paths. Use a short unique `/tmp` runtime root rather than `NSTemporaryDirectory()` plus a full UUID; verify fixture setup before counting behavioral RED.
- Badge visibility requires actual colored paint/contrast checks. Native marker presence or alpha on an opaque panel can pass with no badge ink; align the native marker with the visual offset and inspect light/dark captures.
- Toolbar inbox-seen markers and per-item unread receipts are separate. A rendered inbox may acknowledge only its captured exact event identities; reject stale/closed callbacks and keep unresolved workflow attention independent of read status.
- Editable paste confirmations must return the edited draft and revalidate its UTF-8 size and original owner after the modal. Test distinct native events for distinct key presses, initial Return without forcing focus, and editor Return/IME ownership separately; pre-order alert responder state is not physical focus qualification.
- Footer/gap regressions must mount a populated native workspace and check the terminal's own frame and bottom hit target; empty-workspace geometry is insufficient. AppKit `cacheDisplay` omits a terminal's backing-layer background: validate first/last-row ink and composite the actual layer color before interpreting RGB/alpha, while keeping physical compositor qualification separate.
- Filter closed session membership before any Cmd+K query matching so nonempty queries cannot bypass closed state. Cover empty, partial, exact, and Korean-corrected queries plus retained tabs with native regression tests while preserving explicit recovery paths.
- Keep ordinary shell and zsh on the shared dark rounded terminal body with a green prompt. Verify tab and detail pixels across light and dark schemes while retaining explicit shell tint preferences.
- When testing IME search filtering, exercise the native editor with uncommitted marked text (committed 개 plus marked ㅛ for 개ㅛ -> roy), because skipping preedit updates searches only ro and matches proxysql even when pure matchers pass.

- Compare both glyph alpha coverage and requested RGB when fixing smoothed color text; a nonempty bitmap or alpha-only check can pass incorrectly recolored output. Preserve color-font rendering and bound intermediate coverage surfaces.
- Transparent IME preedit must not repaint the row background. Hide only covered terminal ink through the shared renderer snapshot, convert coordinates using the row render mode, and test normal/doubled rows plus commit/cancel/empty restoration without modifying buffer contents.

- Use `python3 scripts/run-swift.py build|test ...` for local Swift work; it fixes package/scratch/jobs and strips volatile agent variables and credentials before SwiftPM records plugin environments. Keep normal toolchain/locale inputs and explicit native capture switches; never print raw environment objects from build cache metadata.
- Verify referenced paths and exact function labels with `rg` before writing native fixtures. Batch related reproductions, complete independent review, then compile the final changes once; use `--skip-build` only while the compiled implementation is unchanged. Check resource bundles for both GUI and helper before signing/installing.

- Workspace notification dots must use the same durable unread predicate as Activity. A resolved workspace entry or explicit reselection acknowledges captured events across all its tabs; passive refresh must not consume newer events, and read status must not alter running/blocked/error workflow state.
- Nested native test fixtures need their own `@MainActor` annotation; actor isolation on the containing XCTest class does not isolate a nested helper class.

- New-tab focus requests must survive asynchronous renderer creation and mounting. Consume focus once at native attachment, preserve native editors, and validate both the first responder and first typed bytes through `setProcessInputHandler` in no-job fixtures; `TerminalViewDelegate` does not capture LocalProcessTerminalView keyboard writes.

- Split focus tests must cover the native shortcut route and renderer reparenting, not only the selected pane ID. Retain a selected first responder across native moves within its original window; newer pane/editor input and cross-window transfers must cancel that return. Use a fake mux transport and cached inert renderers while E2E is paused.

- Native IME selection must use the same UTF-16 coordinate space as markedRange and attributedSubstring while composing. Verify retained cached AppKit layers and committed-prefix RGBA; direct draw calls bypass invalidation, and NSGraphicsContext bitmap scaling must not be applied twice. Keep physical IME qualification separate.

- Notification-dot exclusions must be enforced in both the shared tab projection and delivery policy; changing defaults alone leaves persisted opt-ins active. Keep unrelated channels and another pane's completion/attention visible in mixed tabs, and remove settings controls for unavailable indicators.
- Explicit terminal close must capture all panes before any stop, retain immutable process/conversation witnesses across retries, and keep intentional-close markers outside legacy-writer state. Use one close/reopen operation lease, exact remote generation reconciliation, and PID-bound output monitors; test failures with fake transports without stopping user jobs.

- Finish source-affecting reviews and focused debug tests before release packaging; late source amendments repeat configuration-switch builds. Keep compiler ownership serial and install one verified final bundle for the authorized batch.

- Activity keyboard navigation must consume plain arrows/Enter in the owning window, preserve selected pane IDs through refresh, and share displayed section/group projection with click actions. Cover exact cross-workspace split targets and empty/IME/editor guards without starting live jobs.
